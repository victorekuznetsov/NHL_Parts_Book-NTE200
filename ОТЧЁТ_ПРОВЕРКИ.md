# Полный каталог NTE200 — отчёт по составу и проверке

Единый интерактивный каталог: самосвал **NTE200 (NHL)**, привод **GE**, двигатель
**Cummins QSK50** + руководства по ремонту/эксплуатации и прайс-лист.
Открывается двойным щелчком по `catalog/index.html` (без сервера и интернета).

## Состав

| Каталог | Разделов | Позиций | Уникальных номеров | Чертежей |
|---|---:|---:|---:|---:|
| NTE200 (самосвал, NHL) | 102 | 2 573 | 1 989 | 179 |
| Привод GE | 5 | 743 | 624 | 80 |
| Двигатель Cummins QSK50 | 96 | 1 774 | 1 091 | 96 |
| **Итого** | **203** | **5 090** | **3 700** | **355** |

- **Цены из прайс-листа:** 1 792 уникальных номера с ценой (CNY без НДС).
- **Руководства:** ремонт — 438 стр., оператора — 108 стр., электросхема 24В — 51 стр.
  Прямые ссылки «Руководство по ремонту (стр. N)» — по 74 разделам.

## Что нового в этой версии

1. **Руководства встроены в каталог.** Кнопка «Документы» + в каждом разделе
   ссылка на нужную страницу руководства по ремонту; в электрических разделах —
   на электросхему 24В.
2. **Анализ заказа** в корзине: разбивка по системам (позиции и суммы),
   покрытие ценами.
3. Двигатель **QSK50** и привод **GE** объединены с каталогом самосвала;
   в меню — группы «Самосвал NTE200» и «Двигатель QSK50».

## Проверка (перепроверено дважды)

- **Полнота номеров:** кросс-проверка по исходным страницам —
  `python3 tools/verify_completeness.py catalog/data/parts.js "<PDF>"` →
  **0 потерянных каталожных номеров** (по всем 314 стр. книги NTE200; GE и QSK50
  сверены по числу токенов номеров — расхождений нет).
- **Файлы:** все **355** чертежей и **3** руководства на месте (0 отсутствуют).
- **Браузерная проверка:** по разделам NTE200 / GE / QSK50 — первая позиция 001
  видна, чертежи загружаются, цены и корзина считаются, ссылки на ремонт
  открываются, ошибок в консоли нет.
- «Пропуски» в нумерации позиций (напр. 14, 44) — это количества/детали
  ремкомплектов без отдельного номера, а не потерянные позиции (подтверждено).

## Как открыть и проверить

1. Скачайте папку `catalog/` (и, при необходимости, `catalog/manuals/`).
2. Откройте `catalog/index.html`. Слева — системы; выберите узел, изучите
   чертёж, добавьте детали в заказ, откройте руководство по ремонту.
3. Выгрузки: «Экспорт всех каталожных номеров (CSV)» и «Экспорт CSV» заказа —
   `catalog/data/all_part_numbers.csv` содержит все аналитики.

## Пересборка из исходников

```bash
pip install pymupdf olefile openpyxl
python3 tools/extract_catalog.py    # книга NTE200 (PDF)
python3 tools/extract_ge.py         # привод GE (Word .doc)
python3 tools/extract_qsk50.py      # двигатель QSK50 (Cummins)
python3 tools/extract_prices.py     # цены и аналитики (XLSX)
python3 tools/extract_manuals.py    # руководства и ссылки на ремонт
python3 tools/verify_completeness.py catalog/data/parts.js
```
