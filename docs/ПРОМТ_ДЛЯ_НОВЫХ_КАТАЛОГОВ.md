# Новый каталог из книги запчастей — что нужно

Есть два способа переиспользовать эту работу для **другой машины/книги**. Выбор
зависит от того, где вы работаете.

---

## Способ 1. Промт (проще всего, ничего устанавливать не нужно)

Начните новую сессию Claude Code **в репозитории с новой книгой** (загрузите туда
исходники: PDF / Word `.doc` / прайс `.xlsx`) и **вставьте промт ниже**. Замените
описание исходников на свои.

> Скопируйте всё, что между линиями:

---
Сделай из приложенных исходников **интерактивный (кликабельный) веб-каталог
запчастей** — по образцу каталога из проекта `NHL_Parts_Book-NTE200`
(папка `catalog/` и навык `.claude/skills/parts-catalog/`). Если этот навык
доступен — используй его; в нём описаны все тонкости разбора таких книг.

Исходники:
- Книга запчастей: <укажи файл: PDF, возможно многотомный `*.zip.001…`, или Word `.doc`>.
- Прайс-лист: <укажи файл `*.xlsx`>, если есть.

Требования к результату:
1. **Разбери таблицы деталей и чертежи из книги.** Разбирай колонки по значению
   (не по фиксированным координатам), учитывай количество «AR», пустое
   количество, буквенно-цифровые номера позиций и строки-подкомпоненты без
   номера детали. **Обязательно** проверь полноту: ни один напечатанный номер
   детали не должен потеряться (сделай кросс-проверку и покажи, что пропущено 0).
2. **Каждый чертёж покажи рядом с его списком позиций** (номер на чертеже =
   номер позиции в таблице). Если у узла несколько листов — сделай карусель.
3. **Таблица:** № · номер детали · наименование · цена · количество на схеме ·
   поле «Нужно» (требуемое количество) · кнопка «＋ в заказ».
4. **Корзина заказа:** редактирование количества, серийный номер машины, сумма
   заказа, выгрузка в CSV и на печать. Сохрани корзину в браузере.
5. **Поиск** по номеру и названию по всему каталогу.
6. **Прайс-лист:** подтяни к деталям цену и все аналитики (группа,
   взаимозаменяемый артикул, наименование). В выгрузке уникальных позиций
   выгружай все аналитики.
7. **Оформление** светлое; вверху строка контактов: «По вопросам работы каталога
   запасных частей, ошибок, замечаний обращаться к Кузнецову В.Е.
   KuznetsovVE@industrservice.ru».
8. Каталог должен открываться двойным щелчком по `index.html` (без сервера).
   Проверь в браузере, что позиция 001 видна в каждом разделе, чертежи
   загружаются, заказ считается, ошибок в консоли нет. Затем закоммить и запушь.

Сделай скрипты пересборки в папке `tools/`, чтобы каталог можно было повторно
собрать из исходников.

## Способ 2. Навык (skill) — если хотите «кнопку», а не промт

Навык уже готов и лежит в этом репозитории: **`.claude/skills/parts-catalog/`**.

- **Тот же репозиторий** — навык подхватывается автоматически, делать ничего не
  нужно.
- **Другой репозиторий** — скопируйте папку `.claude/skills/parts-catalog/` в
  новый репозиторий (и исходники книги). Тогда навык заработает и там.
- **Во всех проектах сразу (личный профиль)** — установите присланный файл
  `parts-catalog.skill` кнопкой «Save skill» на карточке файла в чате. Это
  делается **с компьютера** на claude.ai; в мобильном приложении кнопки нет.

Разница простыми словами: **промт** — вставил текст и поехали, ставить ничего не
надо. **Навык** — «умение» Claude, которое включается само; удобно, если каталоги
делаете регулярно, но для установки в профиль нужен компьютер.

---

Для запуска скриптов пересборки Claude поставит библиотеки:
`pip install pymupdf olefile openpyxl`.
