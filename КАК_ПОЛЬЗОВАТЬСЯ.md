# Как пользоваться каталогом запчастей NTE200

Короткая инструкция без технических подробностей. По вопросам работы каталога,
ошибкам и замечаниям: **Кузнецов В.Е., KuznetsovVE@industrservice.ru**.

---

## 1. Что это

Электронный (кликабельный) каталог запчастей карьерного самосвала **NTE200** и
**привода GE**: чертежи узлов, таблицы деталей с ценами, поиск по всему каталогу
и корзина для формирования заказа.

Всё содержимое лежит в папке **`catalog/`**.

## 2. Как открыть каталог

**На компьютере (проще всего):**
1. Скачайте папку `catalog` из репозитория.
2. Откройте в ней файл **`index.html`** двойным щелчком — каталог откроется в
   браузере. Интернет и установка программ не нужны.

**По ссылке с любого устройства (телефон/планшет):** каталог можно опубликовать
как веб-страницу (GitHub Pages). Если нужна ссылка — напишите, настроим.

## 3. Что умеет каталог

- **Слева — разделы** по системам машины (структура, электрика, гидравлика,
  ходовая, кабина, привод GE и т. д.). Выберите нужный узел.
- **Чертёж рядом со своим списком позиций.** Номер на чертеже (выноска)
  соответствует номеру позиции (№) в таблице. Если у узла несколько листов —
  листайте их стрелками ‹ ›.
- **Таблица деталей:** № · номер детали · наименование · **цена (CNY без НДС)** ·
  количество на схеме · поле «Нужно».
- **Заказ:** в строке укажите в поле «Нужно» требуемое количество и нажмите **＋**.
  Кнопка **«Заказ»** вверху открывает корзину: там можно менять количество,
  указать серийный номер машины, увидеть **сумму заказа** и выгрузить заявку в
  **CSV** или на **печать**.
- **Поиск** (строка вверху): по номеру детали или названию сразу по всему
  каталогу.
- **Экспорт всех номеров:** кнопка «Экспорт всех каталожных номеров (CSV)» —
  выгружает все уникальные позиции со всеми данными (наименование, цена, группа,
  взаимозаменяемый артикул, разделы).

## 4. Как обновить каталог из новой книги запчастей

Это делает Claude — просто откройте сессию по этому репозиторию и попросите,
например: «обнови каталог из новой книги запчастей» или «подтяни свежий
прайс-лист». В проекте уже есть всё необходимое:

- Исходники: PDF-книга (тома `NTE200 PART ... .zip.001…004`), книга привода GE
  (`NTE200 GE...doc`), прайс-лист (`Прайс-лист ГЕ...xlsx`).
- Скрипты пересборки в папке `tools/`:
  - `extract_catalog.py` — из PDF-книги;
  - `extract_ge.py` — из книги привода GE (Word);
  - `extract_prices.py` — цены и аналитики из прайс-листа;
  - плюс проверка полноты, чтобы ни один номер не потерялся.
- Навык (skill) `parts-catalog` в папке `.claude/skills/` — Claude использует его
  автоматически и знает все тонкости разбора этих книг.

Если запускаете скрипты вручную, сначала нужны библиотеки:
`pip install pymupdf olefile openpyxl`.

## 5. Частые вопросы

- **Не вижу позицию 001 / номера «пропадают».** Обновите страницу с очисткой
  кэша: **Ctrl+F5** (Windows) или **Cmd+Shift+R** (Mac) — загрузится актуальная
  версия.
- **Почему в нумерации бывают «пропуски» (например, нет 14, 44)?** Это не
  потерянные детали: такие числа в книге используются как количество, а как
  номера позиций не встречаются. Все реально напечатанные номера в каталоге есть.
- **Цена не у всех деталей.** Цена берётся из прайс-листа; часть позиций там
  пока отсутствует — по мере обновления прайса они добавятся.
- **Цены — в CNY без НДС.** При необходимости добавим пересчёт в рубли и/или НДС.
