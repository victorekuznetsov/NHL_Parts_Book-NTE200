# QSK50 — онлайн-каталог Cummins (исходник)

Выгрузка онлайн-каталога Cummins QuickServe для двигателя серийный № **33239899**
(модель **QSK50 CM2150 MCRS**, CPL 3379):

* `33239899.js` — `window.CATALOGS["33239899"]`: системы, узлы (options), детали,
  и карточки деталей `cards` (вес `wt`, габариты `dim`, характеристики `attrs`).
* `drawings/` — 60 листов-чертежей узлов (PNG).

Из этого исходника `tools/extract_qsk50_online.py` собирает главы **QO01–QO14**
каталога (см. корневой README). Фотографии деталей в исходник не входят — они
грузятся приложением с публичного CDN Cummins по номеру детали.
